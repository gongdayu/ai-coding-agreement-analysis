# Article–label binary data

These two Q1–Q4 tables were rebuilt from the current fixed coding data, using the public IDs. Each has 4,100 rows: 100 articles × (11 + 11 + 8 + 11) allowed labels. `Human` and `GPT` are binary indicators. The columns identify the article, question and allowed label; no original article ID is included.

Both tables are generated by `analysis_code/run_analysis.py`. They replace, rather than merely renumber, the obsolete Method 1 and Method 2 binary tables. Non-codebook predictions do not create extra binary columns; see the scoring rule in `analysis_code/METHODOLOGY.md`.
